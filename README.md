# PVZ Inspired Android

Game prototype lấy cảm hứng từ Plants vs. Zombies, không dùng tài sản gốc của game.

## Có sẵn
- 5 hàng, 9 cột
- Sunflower tạo sun
- Peashooter bắn đạn
- Zombie đi từ phải sang trái
- Máu zombie
- Thắng/thua
- Chạm HUD để chọn cây
- Chạm ô để trồng cây
- Màn chơi tự khởi động lại khi chạm sau thắng/thua

## Mở và build APK
1. Mở thư mục này bằng Android Studio.
2. Chờ Gradle sync.
3. Chọn Build > Build APK(s).
4. APK debug thường nằm ở `app/build/outputs/apk/debug/app-debug.apk`.

Lưu ý: máy cần Android SDK/Gradle phù hợp để build.
